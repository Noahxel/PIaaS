Trading Signal API for Developers

Send a price series. Get a structured BUY/SELL/HOLD signal with confidence score, risk score, and explainable reasoning. No ML setup required.

Demo

Request

curl -X POST /v1/predict \
  -H "X-API-Key: dev-key-1234" \
  -d '{
  "prices": [
    100, 101.5, 99.8,
    102.3, 103.1, 101.9
  ]
}'

Response

{
  "action": "HOLD",
  "confidence": 0.51,
  "expected_value": -0.01,
  "risk_score": 0.18,
  "signal_strength": 0.01,
  "reasoning_signals": [
    "positive momentum (+1.90%)",
    "price above MA5 (+0.55%)"
  ]
}

Use cases

  • Algorithmic trading bot — consume signals in a loop without building an ML pipeline from scratch
  • Financial dashboard — surface structured decisions alongside raw price data
  • Strategy prototyping — get a working signal endpoint in under 5 minutes to validate a trading idea

Get started

1

Install and run

pip install -r requirements.txt
uvicorn main:app --reload
2

Call the API — default key works immediately

curl -X POST http://localhost:8000/v1/predict \
  -H "X-API-Key: dev-key-1234" \
  -H "Content-Type: application/json" \
  -d '{"prices": [100, 101.5, 99.8, 102.3, 103.1, 101.9]}'
3

Or use the Python SDK

from sdk.client import PIaaSClient

client = PIaaSClient("http://localhost:8000", api_key="dev-key-1234")
signal = client.predict([100, 101.5, 99.8, 102.3, 103.1, 101.9])

Response fields

FieldTypeDescription

expected_valuefloatP(up) − P(down)
risk_score0.0–1.0Volatility-based risk estimate
signal_strength0.0–1.0Distance from neutral (0 = no signal)
